# Community Issues

Use GitHub issues for community feedback, bug reports, and small improvement ideas.

## How To Contribute

1. Search existing issues first.
2. Create a new issue with a short title and a clear description of the problem or idea.
3. Include reproduction steps, screenshots, or example queries when they help.
4. Add a label if you know the area, such as `area:ui`, `area:api`, or `area:infra`.

## Good Issue Shape

- What happened
- What you expected
- What you tried
- Any relevant links, screenshots, or queries

If the item turns into planned product work, it can move into [docs/roadmap.md](./roadmap.md) or the autonomous backlog later.
